API bağlantıları

Ayarlar private klasöründeki site_apileri,.txt dosyasına kaydedilir. Anahtarlar müşteriye gösterilmez. Boş anahtar alanı mevcut anahtarı korur.

Önce Telegram’da botunuzu açıp /start gönderin. İlk kurulumda “Bot mesajından ID’leri bul” alanları doldurmanıza yardımcı olur. Onay bağlantısı kurulduktan sonra ID araması çalışmayabilir; kayıtlı ID’leri koruyun.

Onay düğmesi yapılandırdığınız botun onaylarını bu siteye bağlar. Aynı botu başka sitede kullanıyorsanız, o sitenin onay bağlantısı da etkilenir.

Yayın sonrası kontrol

Telegram testini çalıştırın. Onay bağlantısını kurduktan sonra ana sayfadan bir deneme yorumu gönderin; Telegram’dan Onayla/Reddet seçerek yayını kontrol edin.

Başarısız gönderimlerin düzenli tekrarı için Plesk zamanlanmış görevinde worker.php dosyasını her dakika çalıştırın. İlk bildirim yorum kaydında hemen denenir.
